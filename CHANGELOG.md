# Changelog

## v1.0 (first release)
- Complete English translation: every menu and mode (Exhibition, IWGP Title Match, Series Match,
  Challenge the Burning Spirit, Edit Wrestler, Network Match, Wrestler Directory, Options), help
  lines, rules, result banners, league and tournament screens, champion histories and memory card
  messages.
- All 42 wrestlers under their real names, with their Wrestler Directory profiles, and the 735
  different move names in their move sets.
- 130 pictures with text redrawn in English: menu labels, headings, buttons and the in-match
  banners.
- Edit Wrestler: names of up to 16 letters, and its screens laid out again for the English.
- Three patches: English; English (All Unlocked), with the seven hidden wrestlers selectable from
  the start, the Sapporo venue's own unused music and an eighth Edit entrance theme; and Japan (All
  Unlocked), the original game with the same extras.
- A player's guide on GitHub Pages.
